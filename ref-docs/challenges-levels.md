# Phase 1 — Challenges & Levels

| Challenge                    | Memory skill                    | Levels | Progression                                                                                                           |
| ---------------------------- | ------------------------------- | -----: | --------------------------------------------------------------------------------------------------------------------- |
| **1. The Virtual Staircase** | Object + location recall        |      5 | Few objects → timed viewing → more objects → exact placement → partial disappearance                                  |
| **2. The Assembly Line**     | Sequential memory               |      6 | 3-item order → longer sequences → faster presentation → similar items → reverse order → long sequence                 |
| **3. The Grid**              | Spatial memory                  |      6 | Small highlighted pattern → larger grid → more cells → sequential highlighting → exact order → larger ordered pattern |
| **4. The Daily Routine**     | Contextual / associative memory |      5 | Simple associations → object locations in familiar scenes → missing item → changed item → multiple contextual changes |
| **5. The Audio-Visual Link** | Sound + visual association      |      5 | 3 sound-object pairs → more pairs → sound sequences → longer sequences → visual distraction                           |

## Frozen gameplay hierarchy

**Challenge → Level → 2–4 Rounds**

Levels become harder by changing memory demands, object count, timing, similarity, sequence length, placement, or distraction—not merely by increasing grid size.

The challenge/level definitions must eventually be data-driven so challenges and levels can be added, edited, reordered, disabled, or removed without rewriting game logic. Backend/admin design is deferred to the development conversation.
